## Write code using expressive typing (where available)

Expressive typing in signatures of functions, methods, fields etc. provides strong signals about intent to humans as well as AI agents. It can also provide far-reaching consistency guarantees, reduce the amount tests needing to be written, and reduce the amount of code itself through powerful abstractions and generalizations (requires care and a measured approach to not abstract prematurely, abstract to the point of losing focus and forcing disjoint things together or introduce too much indirection / complexity). This ranges from basic types via function-types, generics (type-variables, parametric polymorphism), bounded / constrained parametric polymorphism via subtyping and/or typeclasses, type-level composition via traits / mixins, unions, intersections, algebraic data types (ADT / ADTs: products, co-products etc.), GADTs, F-Bounded Polymorphism to refinement types, type members, linear or affine typing features, dependent types / path-dependent types and session types - as well as combinations of all the former.
